Bottom Sheet

Definición (Figma · “botonsheet”)

Es una superficie que emerge desde el borde inferior de la pantalla y se apoya sobre el contenido principal, sin reemplazarlo. Convive con la vista de origen en lugar de navegar a una nueva ruta: el contexto queda visible (o al menos implícito) detrás de un scrim, y la superficie se puede descartar deslizando hacia abajo, tocando el fondo o cerrando con la X.

Cuándo / para qué
  • Contextual, acciones rápidas, listas, formularios cortos
  • opciones, filtros, detalles, acciones contextuales.

Plataforma: Mobile

Bottom Sheet · Estructura base (Header, Overlay, Content)

Piezas base para armar cualquier bottom sheet de SOFIA: el header (BS_header, con 4 variantes según la propiedad Handle), el overlay que oscurece el chat detrás del sheet y el área de contenido con el placeholder BS / Slot. ¿Qué es?

Una capa anclada al borde inferior de la pantalla. Se usa en mobile cuando el contenido es complementario a lo que el usuario ya está viendo: opciones, filtros, detalles de un ítem, confirmaciones.

¿Qué queremos que comunique la animación?

Entrada: el sheet sube desde abajo como si estuviera oculto fuera del viewport. Esto refuerza la metáfora de que el contenido existía debajo de la pantalla y el usuario lo trajo hacia arriba. No es magia —es un cajón que se abre.

Salida: el sheet baja de nuevo al lugar del que vino. El usuario entiende intuitivamente que el contenido "volvió", no que fue destruido.

Qué evitar
  • No usar scale en el sheet: rompería la metáfora de "cajón físico".
  • No animar el alto del sheet durante la entrada: debe aparecer ya con su tamaño final.
  • No usar ease-in al inicio: el arranque lento en mobile se siente laggy.

// Desliza desde el borde inferior. Incluye overlay con fade.
// Uso:
//   openBottomSheet(sheetEl, overlayEl)
//   closeBottomSheet(sheetEl, overlayEl)

const BOTTOM_SHEET = {
  duration: 320,
  easing: "cubic-bezier(0.32, 0.72, 0, 1)", // spring suave
};

export function openBottomSheet(sheet, overlay) {
  overlay.style.display = "block";

  overlay.animate(
    [{ opacity: 0 }, { opacity: 1 }],
    { duration: BOTTOM_SHEET.duration, easing: "ease", fill: "forwards" }
  );

  sheet.style.display = "flex";
  sheet.animate(
    [
      { transform: "translateY(100%)", opacity: 0.6 },
      { transform: "translateY(0)",    opacity: 1   },
    ],
    { duration: BOTTOM_SHEET.duration, easing: BOTTOM_SHEET.easing, fill: "forwards" }
  );
}

export function closeBottomSheet(sheet, overlay) {
  const anim = sheet.animate(
    [
      { transform: "translateY(0)",    opacity: 1   },
      { transform: "translateY(100%)", opacity: 0.6 },
    ],
    { duration: BOTTOM_SHEET.duration, easing: BOTTOM_SHEET.easing, fill: "forwards" }
  );

  overlay.animate(
    [{ opacity: 1 }, { opacity: 0 }],
    { duration: BOTTOM_SHEET.duration, easing: "ease", fill: "forwards" }
  );

  anim.onfinish = () => {
    sheet.style.display   = "none";
    overlay.style.display = "none";
  };
}

¿Qué es?

Una capa centrada en pantalla que interrumpe el flujo. Se usa para acciones que requieren atención explícita del usuario: confirmaciones destructivas, formularios críticos, alertas importantes.

¿Qué queremos que comunique la animación?

Entrada: el modal aparece levemente más chico y más abajo de su posición final, y crece hasta su tamaño real. Esto imita la sensación de que algo "emerge" del centro de la pantalla hacia el usuario. La leve escala con spring comunica que el elemento tiene "peso" y aterrizó en su lugar.

Salida: el modal se achica ligeramente y baja un poco antes de desaparecer. Va en dirección contraria a la entrada: se "retira", no simplemente desaparece. El usuario percibe que el sistema respondió a su acción de cerrar.

Qué evitar
  • No usar solo opacity sin scale: la transición queda plana y no tiene sensación de profundidad.
  • No exagerar el spring (valores > 1.8 en la curva): el modal es bloqueante y un rebote excesivo distrae.
  • No animar el overlay con delay: debe arrancar al mismo tiempo que el modal.

// ─── Modal · Desktop ─────────────────────────────────────────────────────────
// Aparece centrado con scale + fade. Overlay con blur opcional.
// Uso:
//   openModal(modalEl, overlayEl)
//   closeModal(modalEl, overlayEl)

const MODAL = {
  duration: 260,
  easingIn:  "cubic-bezier(0.34, 1.56, 0.64, 1)", // leve spring en entrada
  easingOut: "cubic-bezier(0.4, 0, 0.2, 1)",       // ease-out estándar en salida
};

export function openModal(modal, overlay) {
  overlay.style.display = "flex";
  modal.style.display   = "flex";

  overlay.animate(
    [{ opacity: 0 }, { opacity: 1 }],
    { duration: MODAL.duration, easing: "ease", fill: "forwards" }
  );

  modal.animate(
    [
      { transform: "scale(0.92) translateY(8px)", opacity: 0 },
      { transform: "scale(1)    translateY(0)",   opacity: 1 },
    ],
    { duration: MODAL.duration, easing: MODAL.easingIn, fill: "forwards" }
  );
}

export function closeModal(modal, overlay) {
  const anim = modal.animate(
    [
      { transform: "scale(1)    translateY(0)",   opacity: 1 },
      { transform: "scale(0.94) translateY(4px)", opacity: 0 },
    ],
    { duration: MODAL.duration, easing: MODAL.easingOut, fill: "forwards" }
  );

  overlay.animate(
    [{ opacity: 1 }, { opacity: 0 }],
    { duration: MODAL.duration, easing: "ease", fill: "forwards" }
  );

Motion · 3. Side Sheet · Desktop

Texto 4181:27785 · Qué evitar 4181:27789 · Código 4123:2476

¿Qué es?

Una capa que ocupa parte del ancho lateral de la pantalla. Se usa en desktop para contenido que complementa la vista principal sin reemplazarla: paneles de detalle, filtros avanzados, configuraciones, chats de soporte.

¿Qué queremos que comunique la animación?

Entrada: el panel desliza desde el borde lateral (derecho por defecto, izquierdo si aplica) hacia adentro de la pantalla. Refuerza la metáfora de que existe un espacio adyacente al viewport y el usuario lo está descubriendo o invocando. Es una extensión del canvas, no una interrupción.

Salida: el panel se retira hacia el mismo borde del que vino. El usuario entiende que el contenido "sigue estando ahí", fuera de la vista, y puede volver a invocarlo.

Qué evitar
  • No usar scale en el side sheet: destruye la metáfora espacial de panel lateral.
  • No animar el ancho del panel durante la entrada: el panel debe tener su ancho final desde el primer frame.
  • No usar el mismo timing corto del modal (260 ms): en desktop el recorrido es mayor y se ve apresurado.
Decisiones de diseño
VariableValorPor qué
Duración340 msEl más largo de los tres. El panel tiene más recorrido horizontal y una animación muy rápida se sentiría brusca en desktop.
Easingcubic-bezier(0.32, 0.72, 0, 1)Mismo spring que el bottom sheet. Ambos son "paneles que deslizan desde un borde"; la coherencia de curva refuerza el lenguaje de movimiento del sistema.
translateX inicio100% (right) / -100% (left)El panel parte desde exactamente fuera del viewport, sin peeks ni reveals parciales.
Opacidad inicio0.8Más visible que el bottom sheet desde el inicio, porque en desktop el movimiento lateral es menos pronunciado perceptualmente.
origin configurable"right" | "left"El panel derecho es el más común (detalle, configuración). El izquierdo se usa para navegación o contexto. La animación es especular; misma curva, dirección opuesta.
OverlayFade simple, más tenueEn desktop el overlay del side sheet suele ser más sutil que el de un modal, porque el contenido principal sigue siendo relevante.

// ─── Side Sheet · Desktop ─────────────────────────────────────────────────────
// Desliza desde el borde derecho (o izquierdo pasando origin: "left").
// Uso:
//   openSideSheet(sheetEl, overlayEl, { origin: "right" | "left" })
//   closeSideSheet(sheetEl, overlayEl, { origin: "right" | "left" })

const SIDE_SHEET = {
  duration: 340,
  easing: "cubic-bezier(0.32, 0.72, 0, 1)",
};

function getTranslate(origin) {
  return origin === "left" ? "translateX(-100%)" : "translateX(100%)";
}

export function openSideSheet(sheet, overlay, { origin = "right" } = {}) {
  const offscreen = getTranslate(origin);

  overlay.style.display = "block";
  sheet.style.display   = "flex";

  overlay.animate(
    [{ opacity: 0 }, { opacity: 1 }],
    { duration: SIDE_SHEET.duration, easing: "ease", fill: "forwards" }
  );

  sheet.animate(
    [
      { transform: offscreen,        opacity: 0.8 },
      { transform: "translateX(0)",  opacity: 1   },
    ],
    { duration: SIDE_SHEET.duration, easing: SIDE_SHEET.easing, fill: "forwards" }
  );
}

export function closeSideSheet(sheet, overlay, { origin = "right" } = {}) {
  const offscreen = getTranslate(origin);

  const anim = sheet.animate(
    [
      { transform: "translateX(0)", opacity: 1   },
      { transform: offscreen,       opacity: 0.8 },
    ],
    { duration: SIDE_SHEET.duration, easing: SIDE_SHEET.easing, fill: "forwards" }
  );

  overlay.animate(
    [{ opacity: 1 }, { opacity: 0 }],
    { duration: SIDE_SHEET.duration, easing: "ease", fill: "forwards" }
  );

  anim.onfinish = () => {
    sheet.style.display   = "none";
    overlay.style.display = "none";
  };
}
